# Learning Roadmap: Computers, Electricity and Programming (from age 7)

At 7, the goal isn't to teach computers yet. It's to build **curiosity, logical thinking and comfort with making things**. Keep sessions short (20–30 minutes), hands-on and fun.

---

## Phase 1 (Ages 7–8): Foundations through play

### 1. Electricity (start here, because it's the most physical)
- **Concepts:** A circuit is a loop. Batteries push electricity. Switches open and close the loop. Some materials conduct electricity and some don't.
- **Activities:**
  - Light a small bulb with a battery, wires and a switch. Break the loop and watch the light go off.
  - Test household items (spoon, eraser, coin, paper) and sort them into conductors and insulators.
  - Make a lemon or potato battery.
- **Kits:** Snap Circuits Jr. (safe, no soldering). Squishy Circuits (conductive play-dough).
- **Safety rule:** Only batteries, never wall sockets.

### 2. Programming (logic first, screens second)
- **Unplugged:**
  - "Robot parent" game: he gives you step-by-step commands to reach a toy. Follow them *literally* so he discovers bugs.
  - Board games: Robot Turtles, Code Master.
- **Screen-based:** ScratchJr (free), Code.org Courses A/B/C, Lightbot, Kodable.
- **Concepts to name:** sequence, loop, bug and debugging, "if this, then that".

### 3. How computers work
- **Core idea:** Input → Process → Output, plus Memory.
  - Keyboard, mouse and mic are the senses (input).
  - The CPU is the brain (process).
  - Memory is a notebook (short-term) and storage is a cupboard (long-term).
  - Screen and speaker are the mouth and hands (output).
- **Activities:** Open an old, unplugged computer or keyboard. Draw a "computer body" poster. Try binary with cards showing 1, 2, 4, 8 and 16 dots (see csunplugged.org).
- **Books:** *Hello Ruby* (Linda Liukas), *How to Code a Sandcastle* (Josh Funk), *Oscar and the Bird* (Geoff Waring).

---

## Phase 2 (Ages 8–10): Connecting the pieces
- **Programming:** Scratch (full version); make simple games.
- **Robotics:** Botley 2.0 or Bee-Bot, LEGO SPIKE Essential and then Prime, micro:bit.
- **Electricity:** bigger Snap Circuits sets and motors. A transistor is a switch controlled by electricity.
- **Architecture:** logic gates as games (an AND gate means both doors must be open). Turing Tumble.

## Phase 3 (Ages 10–13): Real tools
- Python (turtle graphics, CodeCombat)
- Arduino or Raspberry Pi: build a line-following robot
- Simplified nand2tetris ideas; build small logic circuits
- Quantum curiosity: *Quantum Computing for Babies* (Chris Ferrie), Quantum Odyssey

## Phase 4 (Teens): Quantum computing properly
It needs probability, linear algebra and physics. **Build strong maths foundations now**: puzzles, patterns, mental maths, chess, Sudoku.

## Tips for parents
1. **Follow his interest.** Cars → a car circuit. Stories → animate a story in ScratchJr.
2. **Praise debugging:** "You found the bug!"
3. **Let him teach you.**
4. **Limit passive screen time.** Creating is good; watching is not the goal.
5. **Keep a project journal** with photos and drawings.

## Where to start this week
1. Install **ScratchJr**.
2. Buy **Snap Circuits Jr.** (or a basic battery, bulb and wire set).
3. Get ***Hello Ruby: Journey Inside the Computer***.
4. Play the "robot parent" game tonight.
